# robot-manipulation
From Navigation to Manipulation — Advancing Autonomous Robotics
From Navigation to Manipulation — Advancing Autonomous Robotics 🤖

This project builds upon the robot navigation phase, extending capabilities to object manipulation and task execution.
The robot detects and interacts with objects using computer vision, inverse kinematics, and PID control.

🧠 Features:

Environment mapping and path planning with A*

Motion control using PID for precision

Object detection via onboard camera

7-DOF robotic arm control using inverse kinematics

🚀 The project is developed in Webots and integrates perception, planning, and control for real-world robotic applications.
